# Loa Energy 개발 로드맵

> 로스트아크 생명의 기운을 기록하고, 시간에 따른 회복 상태와 완충 예상 시각을 확인하는 Android 앱.

## 개발 방향

- 게임 계정과 직접 연동하지 않고, 사용자가 입력한 생명의 기운과 기록 시각을 기준으로 **예상값**을 계산한다.
- 첫 MVP는 앱 안에서 입력·계산·저장이 동작하는 상태를 목표로 한다.
- 홈 화면 위젯과 알림은 MVP 이후에 추가한다.
- 실제 게임의 회복 규칙과 최대치는 구현 전에 확인하고, 학습용 예시 수치를 실제 규칙으로 간주하지 않는다.

## 첫 MVP 완료 조건

- 사용자가 생명의 기운을 입력하고 저장할 수 있다.
- 시간이 지나면 저장된 시각을 기준으로 현재 생기를 추정한다.
- 계산 결과가 최대 생기를 초과하지 않는다.
- 완충까지 남은 시간 또는 예상 시각을 확인할 수 있다.
- 앱을 다시 실행해도 기록이 유지된다.

## 첫 MVP에서 제외할 기능

- 로스트아크 계정·게임 서버 자동 연동
- 여러 캐릭터 동시 관리
- 홈 화면 위젯 및 알림 (후속 단계에서 구현)
