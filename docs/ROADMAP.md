# Loa Energy 개발 로드맵

> 로스트아크 생명의 기운을 직접 입력하고, 기록 시각을 바탕으로 예상 회복 상태를 앱과 Android 홈 화면 위젯에서 확인하는 프로젝트.

## 개발 원칙

- 로스트아크 계정이나 서버에 자동 연동하지 않는다. 표시 수치는 **예상값**이다.
- 사용자가 확인한 회복 규칙: **10분마다 생명의 기운 30 회복**.
- 계산은 입력한 기록 시각을 회복 주기의 시작으로 가정한다. 실제 게임 내부 회복 시점에 따라 오차가 생길 수 있다.
- 사용자가 직접 Kotlin 코드를 작성하고, 앱 실행 테스트 후 커밋·푸시한다.
- 위젯 백그라운드 갱신은 Android 시스템 상태에 따라 지연될 수 있으며 정확히 10분마다 실행된다고 보장하지 않는다.
