# Loa Energy

로스트아크의 생명의 기운을 계산하고
회복 상태를 확인할 수 있는 Android 애플리케이션

## 프로젝트 시작 이유

게임 로스트아크의 생활 콘텐츠를 하기 위한 생명의 기운은 시간이 지나면 조금씩 차오른다. 하지만 생명의 기운 수치가 최대치에 도달하면 추가 회복이 이루어지지 않는다. 사용자가 완충 시간을 모르고 있으면 회복 가능한 시간을 낭비할 수 있다.  이러한 일을 대비하기 위한 안드로이드 홈 화면 위젯이 있다면 편리할 것 같다고 생각해 이 프로젝트를 시작하게 되었다.

## 주요 기능

### 구현 완료
- [x] 생명의 기운 기본 화면 출력

### 개발 예정
- [ ] 현재 생명의 기운 입력
- [ ] 시간에 따른 생명의 기운 회복량 계산
- [ ] 입력 정보 저장
- [ ] 생명의 기운 위젯
- [ ] 회복 완료 알림

## 기술 스택

- Platform: Android
