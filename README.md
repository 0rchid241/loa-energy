# LOA Energy — 로스트아크 생명의 기운 계산기

> 로스트아크의 생명의 기운 회복량과 완충 예상 시간을 계산하고, Android 홈 화면 위젯에서 예상 수치를 확인하는 개인 프로젝트

**개발 상태:** 앱·위젯 핵심 MVP 구현 완료, 안정화 진행 중

## 프로젝트 소개

로스트아크의 생활 콘텐츠에 사용하는 **생명의 기운**은 시간이 지나면 회복되지만, 최대치에 도달하면 추가 회복되지 않습니다. 게임을 실행하지 않고도 회복 상태와 완충 예상 시간을 확인할 수 있도록 Android 앱과 홈 화면 위젯을 개발했습니다.

이 앱은 로스트아크 계정이나 서버와 연동하지 않습니다. 사용자가 입력한 생명의 기운과 기록 시각을 바탕으로 **예상값**을 계산합니다.

## 기술 스택

| 구분 | 기술 |
| --- | --- |
| 언어·플랫폼 | Kotlin, Android (minSdk 26) |
| 앱 UI | Jetpack Compose, Material 3 |
| 홈 화면 위젯 | Jetpack Glance |
| 로컬 데이터 저장 | Preferences DataStore |
| 백그라운드 갱신 | WorkManager |
| 비동기·상태 처리 | Kotlin Coroutines, Flow |

## 구현 기능

### 생명의 기운 입력 및 회복 계산

- 현재 생명의 기운과 최대 생명의 기운 입력 및 유효성 검사
- 저장된 기록 시각부터의 경과 시간 계산
- **10분마다 생명의 기운 30 회복** 규칙과 최대치 제한 적용
- 앱 실행 중 예상 생기 자동 갱신
- 완충까지 남은 생기의 양, 예상 소요 시간 및 완충 예상 시각 표시

### 데이터 저장과 복원

- DataStore에 기준 생기, 최대 생기, 기록 시각 저장
- 앱 재실행 시 저장된 값 복원
- 앱을 닫아 둔 동안의 경과 시간도 예상 생기에 반영

### 홈 화면 위젯

- Jetpack Glance 기반 Android 홈 화면 위젯 제공
- 앱과 같은 DataStore 기록을 이용해 현재 예상 생기 표시
- 앱에서 새로운 생기 정보를 저장하면 위젯 갱신 요청
- WorkManager를 통한 백그라운드 주기적 위젯 갱신 요청

> 위젯의 실제 갱신 시점은 Android의 백그라운드 실행 정책에 따라 지연될 수 있습니다.

## 주요 구현 경험

### 1. 기록 시각을 기준으로 한 상태 계산

사용자가 입력한 생기를 단순히 화면에 저장하는 대신 **기록 시각과 현재 시각의 차이**로 회복량을 계산했습니다. 10분 단위의 회복 횟수와 최대 생기 제한을 적용하며, 앱 화면은 Coroutine을 사용해 주기적으로 예상값을 갱신합니다.

### 2. 앱과 위젯의 데이터 공유

앱과 위젯이 서로 다른 상태를 따로 저장하지 않도록 DataStore의 생기 기록을 공통 기준으로 사용했습니다. 저장 후에는 Glance 위젯 갱신을 요청하고, 위젯은 저장된 시각을 기준으로 예상 수치를 다시 계산합니다.

### 3. 위젯 자동 갱신 문제 대응

초기에는 앱에서 생기를 다시 저장했을 때만 위젯 수치가 최신 상태로 보이는 문제가 있었습니다. DataStore 변경 감지 및 위젯 갱신 흐름을 보완하고, WorkManager를 이용해 앱이 열려 있지 않을 때도 위젯 갱신을 요청하도록 수정했습니다.

관련 변경: [DataStore 변경 감지](https://github.com/0rchid241/loa-energy/commit/e86b187c6c38cc861c13251eab5e1ce69d23485e) · [WorkManager 갱신](https://github.com/0rchid241/loa-energy/commit/102cdab47c1f487fed43c50f89b3658a957b13b2)

## 사용 방법

1. Android Studio에서 `app` 모듈을 기기에 설치·실행합니다.
2. 앱에서 **현재 생명의 기운**과 **최대 생명의 기운**을 입력합니다.
3. **적용** 버튼을 누르면 입력값과 기록 시각이 저장됩니다.
4. 앱 화면에서 예상 생기와 완충 예상 시간을 확인합니다.
5. Android 홈 화면에 **LOA Energy** 위젯을 추가해 예상 생기를 확인합니다.

## 현재 제한 사항

- 게임 서버와 직접 연동하지 않으므로 표시되는 생기는 **예상값**입니다.
- 입력 시각을 회복 주기의 시작으로 가정하여 실제 게임 내부 회복 시점과 차이가 발생할 수 있습니다.
- 완충까지 남은 시간은 현재 구현상 근사치입니다. 진행 중인 회복 주기의 경과 시간과 완충 후 표시 처리는 개선이 필요합니다.
- 위젯에는 WorkManager 반복 갱신과 위젯 XML의 갱신 주기 설정이 함께 존재해, 갱신 정책 정리가 필요합니다.
- **완충 알림 기능은 아직 구현되지 않았습니다.**
- 계산 로직의 전용 단위 테스트와 정식 배포·출시 검증은 완료되지 않았습니다.
